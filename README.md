Hey there! Welcome to my Pexels Image Gallery project – a sleek, modern web app that lets you explore stunning free-to-use images from Pexels' massive collection.

✨ What This App Does
Discover beautiful images - Browse through gorgeous, high-quality photos

Find exactly what you need - Search for any topic or keyword

Save your favorites - Heart images to save them for later

Responsive design - Works perfectly on phones, tablets, and computers

🛠️ Built With
React - For building interactive components

Tailwind CSS - For beautiful, modern styling

Pexels API - For accessing millions of free images

Vite - For super fast development
