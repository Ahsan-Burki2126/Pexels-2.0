# 🌄 Pexels Image Gallery - A Beautiful Image Discovery App

**Hey there!** Welcome to my Pexels Image Gallery project – a sleek, modern web app that lets you explore stunning free-to-use images from Pexels' massive collection.

## ✨ What This App Does

- **Discover beautiful images** - Browse through gorgeous, high-quality photos
- **Find exactly what you need** - Search for any topic or keyword
- **Save your favorites** - Heart images to save them for later
- **Responsive design** - Works perfectly on phones, tablets, and computers

## 🛠️ Built With

- **React** - For building interactive components
- **Tailwind CSS** - For beautiful, modern styling
- **Pexels API** - For accessing millions of free images
- **Vite** - For super fast development

## 🚀 Getting Started

### Prerequisites

You'll need:

- Node.js (version 16 or higher)
- A Pexels API key (get one for free at [pexels.com/api](https://www.pexels.com/api/))

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/pexels-gallery.git
   cd pexels-gallery
   ```

2. Install the required packages:

   ```bash
   npm install
   ```

3. Create a `.env` file in the root folder and add your Pexels API key:

   ```
   VITE_PEXELS_API_KEY=your_api_key_here
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser to `http://localhost:3000` and start exploring!

## 📸 Features in Action

1. **Search Anything**  
   Type in keywords like "mountains", "coffee", or "city" to find relevant images.

2. **Save Your Favorites**  
   Click the ❤️ icon on any image to save it. View all your saved images by clicking the heart button in the bottom-right corner.

3. **Load More Images**  
   Found something you like? Click "Load More" to keep exploring.
